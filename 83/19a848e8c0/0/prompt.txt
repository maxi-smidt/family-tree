   │ Findings (by severity)                                                                                                                                                                                   │
   │                                                                                                                                                                                                          │
   │ 1. Low — mtime race defeats retention for old files (storage.py,                                                                                                                                         │
   │    trash_media). shutil.move preserves the original mtime;                                                                                                                                               │
   │    os.utime(dest, None) stamps the move time only afterwards. A file uploaded                                                                                                                            │
   │    │ 30 days ago has an already-expired mtime in the window between move and                                                                                                                             │
   │    │ utime — a concurrent sweep purges it instantly. Worse: if os.utime fails,                                                                                                                           │
   │    │ the exception is swallowed and the file is purged at the next sweep,                                                                                                                                │
   │    │ silently voiding the 30-day retention. Stamping the source before the                                                                                                                               │
   │    │ move (or encoding the trash timestamp in the dest name) closes this.                                                                                                                                │
   │                                                                                                                                                                                                          │
   │ 2. Low — silent failure mode is worse than delete_media's (storage.py).                                                                                                                                  │
   │    trash_media swallows all OSError/ValueError with no logging. A failed                                                                                                                                 │
   │    move leaves the bytes in the live tree dir with the DB row already gone:                                                                                                                              │
   │    the file counts against quota forever and is never purged (it's not in                                                                                                                                │
   │    .trash). delete_media had the same never-raise contract, so this is                                                                                                                                   │
   │    parity not regression — but trash now carries the retention promise, so at                                                                                                                            │
   │    minimum a logger.warning is warranted.                                                                                                                                                                │
   │                                                                                                                                                                                                          │
   │ 3. Low — mtime as the retention clock is fragile. Any external touch                                                                                                                                     │
   │    (rsync, backup restore, admin poking around) shifts mtimes and extends or                                                                                                                             │
   │    shortens retention unpredictably. A timestamped filename prefix or a small                                                                                                                            │
   │    manifest would be robust; the current design is schema-free and simple,                                                                                                                               │
   │    which is a fair trade while no restore endpoint exists — but it should be a                                                                                                                           │
   │    conscious decision.                                                                                                                                                                                   │
   │                                                                                                                                                                                                          │
   │ 4. Nit — purge leaves empty dirs forever (purge_expired_media_trash).                                                                                                                                    │
   │    Files are unlinked but .trash/ and .trash/originals/ are never removed;                                                                                                                               │

   │ Challenges to the implementation                                                                                                                                                                         │
   │                                                                                                                                                                                                          │
   │ • Quota freed instantly, disk held 30 days. Net disk usage can now grow by                                                                                                                               │

   │   self-hosts the fixed MEDIA_TRASH_TTL_SECONDS can't be tuned. The "no                                                                                                                                   │
   │   restore endpoint → internal detail" rationale is reasonable, but an env                                                                                                                                │
   │   override costs almost nothing. At minimum, ops docs should mention the new                                                                                                                             │
   │   disk-usage behaviour.                                                                                                                                                                                  │
   │ • Retention story is still incomplete for the undo goal. Member photos are                                                                                                                               │

   │   archives now include up to 30 days of trashed bytes. Arguably desirable                                                                                                                                │

   │   side effect.                                                                                                                                                                                           │
